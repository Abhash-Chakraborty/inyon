Plan · 1 March 2027 · from 2.3

Shared lists that work offline

Pantry lists sync only while you have signal, so the shop is where they break. This plan makes every list work offline on the phone, merges edits when you're back, and adds recipes that fill a list for you.

    01Short version

    • Lists work with no signal. Every list lives on the phone first and syncs when it can.
    • Edits merge, nothing is lost. Two people ticking the same list offline both see the right result.
    • Recipes fill a list. Pick three dinners and the missing ingredients land on the shop list.

    Today a list is a row on the server and the app shows a spinner until it loads. In a basement shop with no signal, people see an empty screen.
