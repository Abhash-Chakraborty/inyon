# Code of conduct

Inyon is a small project, and everyone who opens an issue, reviews code or sends a pull request
should be able to do it without being harassed or talked down to.

- Be kind and assume good faith. Criticise code and ideas, not people.
- No harassment, slurs, sexual content, personal attacks or publishing someone's private details.
- Keep discussions on topic. Off-topic or abusive comments are hidden or deleted.

The maintainer may edit or remove comments, close issues and pull requests, and block anyone who
breaks these rules, in this repo or its releases.

To report a problem privately, email abhashchak14@gmail.com. Reports are read only by the
maintainer and kept confidential.

This follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
