02 · Computer

Set up a computer

Run one line in a terminal. It prints a QR code; in the app, tap Add a computer and scan it.

macOS or Linux

curl -fsSL https://inyon.abhashchakraborty.tech/get.sh | sh

Windows, in PowerShell

irm https://inyon.abhashchakraborty.tech/get.ps1 | iex

Optional · Browser

Use it from any browser with your own hub

A hub is a small server on one of your machines. It serves the web app, reaches your other machines, and your phone can pair with it too.

curl -fsSL https://inyon.abhashchakraborty.tech/get.sh | sh -s -- --hub

How it connects

Three ways in. Pick per machine.

Mix them freely. A laptop can pair straight with your phone while a server joins a hub, and a locked-down box needs nothing but SSH.

Paired

Phone ↔ computer

Run inyon on the computer and scan its QR code. No hub, no open ports: it reaches your phone through a free encrypted tunnel or your VPN.

Pairing a computer →

Hub

One place for everything

A hub on a machine that stays on serves the web app to any browser. Other machines join it, and your phone pairs with it by QR.

Direct

Just SSH

Can't install anything? The Android app or a hub reaches a server over SSH. The server only needs tmux and your agents.

What you can do

Everything you'd do at the keyboard.

  • Read sessions as a chatReplies, tool calls, diffs, plans and to-dos, with the real terminal one tap away.
  • Answer with buttonsPermission requests, questions, menus and sign-in links, straight from the overview.
  • Steer the agentSwitch model, effort and permission mode, set a goal, compact, clear and rewind.
  • Watch the limitsModel, context, cost and lines changed, plus the 5-hour and weekly plan limits.
  • Type like you're there/ commands, @ file search, ! shell commands and images. Drafts mirror into the terminal.
  • Follow background workQueued messages, subagents and background shells with live output and a real Stop.
  • Get notifiedWhen an agent needs you or finishes, and when a machine drops off or comes back.
  • Set up machines from the appIt checks for tmux and each agent, installs what's missing and opens sign-in.
