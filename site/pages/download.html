Every file

From 0.19 a computer needs one file, inyon, and from 0.21 a hub does too. Only a hub put back on Bun also needs inyon-engine, the program built with Bun. Most people never download these by hand; the installer does it.

The inyon-skill-*.tar.gz files are agent skills, such as Blueprint for plan pages. Install one with inyon skill add <name>, or unpack it into your agent's skills folder.

Checking a download

The release's list of checksums is signed with minisign. Check the list's signature against Inyon's release key, then the files you downloaded against the list:

shell
curl -fsSLO https://inyon.tech/download/SHA256SUMS
curl -fsSLO https://inyon.tech/download/SHA256SUMS.minisig
minisign -Vm SHA256SUMS -P RWRTvQv/ifQnD3jarY1oarS0AKdhogH+mdgn/o0NzT/Ro8L43nFqqfp6
sha256sum --ignore-missing -c SHA256SUMS

On macOS, use shasum -a 256 -c in place of sha256sum -c. Releases before 0.14 have no signature; their lists are on GitHub.

Older versions, release notes and the source are on GitHub releases. The changelog lists what changed in each one.
