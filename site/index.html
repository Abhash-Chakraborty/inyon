Get started

01 · Phone

Install the Android app

Download the APK and open it. Later versions install over it, and the app tells you when one is out.

Download for Android
From the latest release on GitHub
02 · Computer

Set up a computer

Run one line in a terminal. It prints a code; scan it in the app with Add a computer.

macOS or Linux
curl -fsSL https://inyon.abhashchakraborty.tech/get.sh | sh
Windows, in PowerShell
irm https://inyon.abhashchakraborty.tech/get.ps1 | iex
Optional · Browser

Use it from a browser with your own hub

A hub is a small server you run on one of your machines, reached over your private network. Open it from any browser.

curl -fsSL https://inyon.abhashchakraborty.tech/get.sh | sh -s -- --hub
